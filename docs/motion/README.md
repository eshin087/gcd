# Timing cards

One card per move or effect studied from the owner's reference footage (source never named, frames never
committed). A card is what an agent measured, in seconds from first contact (f0) at the footage's frame rate,
plus what we do with it. Format: a one-line what-it-is; phases with times; sizes relative to the body; colours
and motion words; chain / rhythm rules; camera; "Ours" = how it translates to the letters look.

| Card | What |
|---|---|
| [deflect.md](deflect.md) | the perfect deflect: bloom at the contact, sparks, chain rhythm |

Add a row when you add a card. Bodies (poses, limbs) are not cards: see `docs/MOTION.md` section 5.
